# Memento

An autonomous memory treasury: remembers what matters, knows what it can afford.

## Product

- A polished, interactive decision lab with honest scenario labels.
- Real Calibration account reads, SDK quotes, budget gate, signed receipts, uploads and byte-verified retrieval.
- A local worker repeats the observe/decide/act loop without browser clicks. Public demo exposes reads and a simulation; mutations need an operator token.
- Protected source memories remain intact. Compaction is extractive. Rejected content remains local; no claim of deleting paid pieces or immediately lowering existing rails.
- Baseline comparison prices one piece per memory vs one selected archive, including operation fees and dataset proving fees.

## Scope and evidence

Chain: Calibration (314159) only. No mainnet. Fresh test wallet, test funds only. Public receipt export excludes keys. Final Loops project creation/submission and public X posting await the user.
